# App Store localization and screenshots

For version 2.0.0 and later, use these App Store localizations in this order:

1. English (U.S.), the primary localization
2. French
3. German
4. Greek
5. Italian
6. Portuguese (Brazil)
7. Spanish (Spain)

Capture a complete set of App Store screenshots for every localization using all three designated simulators, `Screenshot 0 (*)`, `Screenshot 1 (*)`, and `Screenshot 2 (*)`. Run the `We Are Never Alone (For Screenshots)` target on these simulators. Alternate light and dark appearance between consecutive screenshots in each set.

Do App Store screenshot work on the RedT5 external drive to conserve space on the main drive. Save finished screenshots in `/Volumes/RedT5/We Are Never Alone Screenshots/`. Keep drafts, previews, temporary capture files, and screenshot build output, including Xcode DerivedData, in a separate working directory on `/Volumes/RedT5/`.
