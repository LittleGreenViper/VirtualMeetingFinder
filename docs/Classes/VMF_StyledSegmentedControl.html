VMF_StyledSegmentedControl

@MainActor
class VMF_StyledSegmentedControl : UISegmentedControl

Matches Recovrr’s text switches: six-point outer corners and an inset rectangular selection. UIKit owns the labels, selection, actions, and accessibility. On iOS 26 and later, public background-image APIs preserve the rectangular style instead of the native capsule.
