Search View Controller

  • VMF_MainViewController

    Coordinates the main meeting list, time-slot paging, and meeting-name search.

    Selection model

    Day indexes use 0 for meetings in progress and 1 through 7 for Sunday through Saturday. isNameSearchMode enables name search independently of the stored day and time indexes; search is not a weekday index. A time index is a zero-based position among the sorted, distinct local start times for a weekday. lastTime stores an HHMM value instead.

    VMF_DayTimeSelectionViewController presents the weekday/time picker and search field from the navigation title button. VMF_DayTimeSearchPageViewController embeds the current meeting table and allows adjacent time-slot swipes outside search mode. Selecting Now explicitly displays all meetings in progress. The first forward swipe from Now selects the first available start after the current local time; the first backward swipe selects the latest start at or before now.

    Search filters the name-sorted collection as text changes and preserves the underlying time selection. Local attendance selections are available from a separate VMF_AttendanceViewController screen when at least one meeting is marked.

    See more

    Swift

    @MainActor
class VMF_MainViewController : VMF_BaseViewController, VMF_MasterTableControllerProtocol
    extension VMF_MainViewController: UIPageViewControllerDataSource
    extension VMF_MainViewController: UIPageViewControllerDelegate
